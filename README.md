# Semillero

**Semillero** is an OSINT domain seed generator written in Python.

Its purpose is to collect domain names from multiple public sources and produce reusable datasets for reconnaissance workflows.

The project is technology-agnostic and focuses on domain collection rather than vulnerability scanning or fingerprinting.

## Status

🚧 Work in Progress

Current milestone: Bootstrap completed.

## Goals

- Collect domains from multiple public sources.
- Normalize collected data.
- Remove duplicates.
- Export reusable domain lists.
- Remain modular and maintainable.
